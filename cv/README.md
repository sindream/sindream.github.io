# CV source

The current PDF is a public research CV generated from verifiable public records:

- GitHub profile and owned repositories
- ORCID `0000-0002-6155-3712`
- DOI metadata for the listed IEEE Robotics and Automation Letters papers

Edit `cv_data.json`, then run:

```bash
python3 cv/build_cv.py
```

The builder writes the website-ready PDF to `docs/assets/cv/woojae-shin-cv.pdf`.

Education, employment dates, exact title, department, and direct contact details are intentionally omitted until confirmed by the owner.
